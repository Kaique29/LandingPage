# Landing Page — Kaique Rodrigues DEV

Landing page pessoal desenvolvida com HTML, CSS e JavaScript puro, sem frameworks.

🔗 **Acesse online:** https://kaique29.github.io/landingpage/

## Seções

- Hero com efeito de digitação
- Sobre mim
- Tecnologias
- Projetos (com links para os repositórios)
- Contato

## Tecnologias utilizadas

- HTML5
- CSS3 (variáveis, grid, flexbox, dark/light mode automático)
- JavaScript (vanilla)

## Como rodar localmente

Basta abrir o arquivo `index.html` no navegador, não há build nem dependências.
